# All The Things

Dalamud plugin for Final Fantasy XIV that shows which collectibles are still
missing in the current zone – inspired by "All the Things" from World of Warcraft.

## Features

- **Supported categories:** Mounts, minions, orchestrion rolls, bardings,
  emotes, facewear (glasses), fashion accessories, and Triple Triad cards.
- **Compact overlay** – a slim, borderless companion window that shows only
  missing collectibles for the current zone. Freely movable, resizable, and
  adjustable in transparency.
- **Vendor map links** – clickable vendor names open the in-game map with a
  flag at the researched NPC location.
- **Price & currency display** – price with icon per entry, plus an overview
  of how much of each required currency you currently own, in the overlay.
- **Affordability filter** – optionally shows only collectibles you currently
  have enough of the required currency for.
- **Type filter & ordering** – each category can be shown/hidden individually,
  with a freely adjustable order in the overlay.
- **German/English** – the interface automatically follows the language set
  in the game client (German, falling back to English otherwise).
